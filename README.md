# PixelForge

PixelForge is a collection of creative coding projects that turn code into visual art. Built with languages like Python, JavaScript, Java, and HTML, the projects create everything from simple flowers to intricate designs.

## Projects

Browse the folders to explore each artwork and the code behind it.

## Run a Project

Open the project folder and follow any instructions included there. Requirements and run steps may vary by language.
